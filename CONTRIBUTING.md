# Contributing

Thanks for your interest. Contributions are welcome across all public ISD Labs repos.

## The basics

- Open an issue before starting significant work — avoids wasted effort
- Keep it simple. KISS applies here.
- Match the style of the existing code
- Test your changes before submitting a PR

## Pull requests

- One thing per PR
- Write a clear description of what and why
- Reference any related issues

## Reporting bugs

Open an issue with:
- What you expected to happen
- What actually happened
- Steps to reproduce
- OS and relevant version info
