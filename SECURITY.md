# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report them privately via GitHub's [private vulnerability reporting](https://github.com/isd-labs/.github/security/advisories/new),
or by email to arnvid@gmail.com.

Include as much detail as you can — what the issue is, how to reproduce it, and potential impact.
You'll get a response as quickly as possible.
