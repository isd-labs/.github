# ISD Labs

**Internet Service Design** — tools, experiments, and a bit of history.

ISD started in the early 90s as **Insane Software Designers**, a coding and scene group
out of the BBS/IRC era. Today it's the umbrella for independent software work that doesn't
fit neatly anywhere else — utilities, ops tools, and open-sourced projects
from a few decades of building things.

---

## What's here

- **BBS & IRC era software** — modernized ports and archives from the scene days
- **Ops & infrastructure** — standalone tools for cloud and system operations
- **Experiments** — things that started as a one-off and turned into something
